# DSA 45 Day Practice

I'm using this repo to track my DSA preparation over the next 45 days.

The main goal is to get better at actually solving problems rather than just knowing the theory.

## How I'm using this

For each problem I try to:

- understand what is being asked
- think about a brute force approach first
- try to find a better pattern/approach
- code it myself
- only look at a hint/solution if I'm stuck
- write down the main idea and mistakes after solving

I'm keeping the code here and short notes separately.

## Progress

I'll update the `NOTES.md` file inside each day as I complete it.

## Folder structure

```text
Day_01/
Day_02/
...
Day_45/

Notes/
```

The day folders follow the DSA calendar I'm currently following.

## Notes

`Notes/patterns.md` - patterns and things I want to remember

`Notes/mistakes.md` - mistakes I keep making

`Notes/templates.md` - useful code/pseudocode templates

This is mainly for my own practice and revision.
